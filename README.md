Student Management System

A Student Management System developed in C to manage student records and attendance using file handling.

This project is designed as a practical academic project to understand how C programming concepts can be used to build a real-world application.

Features

- Owner account creation and login
- Login protection with 3 attempts
- Forgot password functionality
- Add student records
- View all student records
- Search students by roll number
- Update student information
- Delete student records
- Mark student attendance
- View attendance records
- Binary file handling for data storage

Technologies Used

- Programming Language: C
- Compiler: GCC / MinGW
- IDE: Code::Blocks / Visual Studio Code
- Storage: Binary files (".dat")

Files Used

- "owner.dat" – Stores owner login information
- "students.dat" – Stores student records
- "attendance.dat" – Stores attendance records
- "temp.dat" – Temporary file used during update and delete operations

C Concepts Used

This project provides practical implementation of:

- Structures
- Functions
- File Handling
- Binary File Operations
- "fread()" and "fwrite()"
- "fseek()"
- "rewind()"
- "remove()" and "rename()"
- String Handling
- Conditional Statements
- Loops
- Switch Case
- Menu-Driven Programming
- Basic Authentication Logic

Project Purpose

The main purpose of this project is to improve practical knowledge of C programming, data management, file handling, and problem-solving by developing a small real-world application.

This project was developed as part of my BCA academic and programming practice.
